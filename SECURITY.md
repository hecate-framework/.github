# Security policy

hecate is pre-release software. No version is supported for production use yet. Once
releases begin, the latest minor version receives security fixes.

Report vulnerabilities privately, through a
[security advisory on the monorepo](https://github.com/hecate-framework/hecate/security/advisories/new)
or by email to <theandre.bourry@ik.me>. This applies to every repository of the
organisation, the read-only `hecate-<package>` mirrors included.

Do not open public issues for security problems.
