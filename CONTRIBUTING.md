# Contributing to hecate

Thank you for your interest. All development happens in the monorepo,
[hecate-framework/hecate](https://github.com/hecate-framework/hecate).

Repositories named `hecate-<package>` are read-only mirrors of the monorepo's
`packages/` directory. Pull requests opened on a mirror are closed automatically.

Read the monorepo's
[contributing guide](https://github.com/hecate-framework/hecate/blob/main/CONTRIBUTING.md)
before you start. It covers the vision, the glossary, decision records, coding
standards and commit conventions.
