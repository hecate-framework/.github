# Getting help

hecate is at the specification stage, so the design documents are the best reference.

- Start with the [vision](https://github.com/hecate-framework/hecate/blob/main/docs/vision.md),
  the [glossary](https://github.com/hecate-framework/hecate/blob/main/docs/glossary.md) and
  the [architecture specifications](https://github.com/hecate-framework/hecate/tree/main/docs/architecture).
- Search the [existing issues](https://github.com/hecate-framework/hecate/issues) of the monorepo.
- Ask a question or report a bug by
  [opening an issue on the monorepo](https://github.com/hecate-framework/hecate/issues/new/choose).
  Issues opened on a `hecate-<package>` mirror are not followed.
- For security problems, follow the [security policy](SECURITY.md) instead.
